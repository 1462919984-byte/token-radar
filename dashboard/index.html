The value model

implied_value_usd = comps_value_usd × token_odds

Comps value fits the market’s TVL→market-cap curve on every protocol that already records a token, then applies it to pre-token protocols. Token odds is the fitted chance one issues a token, discounted by how long it has run tokenless. Both are fit from the snapshot’s own figures — no hardcoded names.
